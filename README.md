## Determinant Calculator

This project allows users to calculate the determinant of 2×2 and 3×3 matrices through an interactive menu-driven interface.

Features

- Select the matrix size (2×2 or 3×3).
- Option to cancel and exit the program.
- User-friendly matrix input form with labeled placeholders for each matrix element.
- Dynamic assignment of values to matrix entries.
- Displays the completed matrix after all values are entered.
- Calculates and displays the determinant of the matrix.

Matrix Templates

2×2 Matrix

[[ A  B ]

 [ C  D ]]

3×3 Matrix

[[ A    B    C ]

 [ D    E    F ]
 
 [ G    H    I ]]

Users are prompted to enter a numerical value for each labeled element (A, B, C, etc.). After all values are provided, the program displays the completed matrix and calculates its determinant.

How It Works

1. The user selects the desired matrix size from the menu.
2. A matrix template with labeled elements is displayed.
3. The user enters a numeric value for each matrix element.
4. The completed matrix is shown on the screen.
5. The program calculates and displays the determinant of the matrix.
